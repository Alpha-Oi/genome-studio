# Genome Studio

Рабочая среда (workbench) для исследователей генной инженерии.

## Что это

Genome Studio принимает цель пользователя на естественном языке,
предлагает стратегии воздействия, разворачивает дерево последствий
(ген → белок → путь → фенотип), симулирует правки, анализирует
и экспортирует результат.

## Ключевые особенности

- **Интент-слой**: цель на естественном языке → план действий.
- **BioKG**: граф биологических знаний для reasoning.
- **Consequence Explorer**: дерево последствий правки.
- **Воспроизводимость**: каждое действие фиксируется.
- **Три уровня безопасности**: T0 (наука), T1 (биобезопасность), T2 (закон).
- **Две сборки**: prod для всех, dev только локально для разработчика.
