# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.1.x  | активная |
| < 0.1  | нет |

## Сообщить об уязвимости

Не открывай публичный issue для уязвимостей.

Отправь приватный отчёт:

1. Через GitHub Security Advisories.
2. Опиши: где, как воспроизвести, что может произойти.
3. Дай время на исправление до публичного раскрытия (обычно 90 дней).

Ожидаемое время реакции: 7 рабочих дней.

## Область безопасности

Проект обрабатывает биологические данные и генерирует последовательности. Особое внимание:

- DURC screening: предупреждения для potential dual-use research of concern (заложено, уровень T1).
- Pathogen sequences: фильтр заложен в Policy Layer (T1, план).
- Local mode: не имеет пароля. По умолчанию слушает только 127.0.0.1. Не запускай на 0.0.0.0 без server-mode.
- Dev Override: только в изолированной локальной сборке. В prod-сборке отсутствует.

## Известные ограничения

- В local mode нет авторизации (by design).
- Multi-user режим заложен архитектурно, но не реализован.
- LLM-парсер (план) будет обрабатывать цели пользователя, потребует отдельного security review.
