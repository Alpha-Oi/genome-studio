# Обзор проекта

## Что такое Genome Studio

Genome Studio — рабочая среда (workbench) для исследователей
генной инженерии и смежных областей. Это «IDE для биолога»:
объединяет симуляцию, редактирование, анализ и notebook
в одну среду с интент-слоем.

## Проблема

Современный исследователь работает с 10+ инструментами:
- SnapGene / Geneious — редакторы последовательностей.
- Benchling — ELN + молекулярка.
- IGV / JBrowse — браузеры.
- Jupyter + Biopython — скрипты.
- VEP / SpliceAI / CADD — предикторы.
- BWA / samtools — выравнивание.

Данные разбросаны, воспроизводимость страдает,
интент пользователя теряется между инструментами.

## Решение

Единая среда, где:
1. Пользователь формулирует цель на естественном языке.
2. Система предлагает стратегии воздействия.
3. Разворачивает дерево последствий.
4. Симулирует, анализирует, экспортирует.
5. Всё фиксируется, воспроизводится, шарится.

## Ключевые принципы

1. Наука свободна, ответственность явная, закон непреклонен.
2. LLM понимает язык, но решения принимает движок.
3. Каждое действие воспроизводимо.
4. Каждое предупреждение — объект, не всплывашка.
5. Dev — для тестирования, не для производства.
6. Пользователь — учёный, а не программист.
7. Никогда не выдавай предсказание за факт.
8. Одна кодовая база, две сборки.
9. Изоляция dev — защита разработчика.
10. Модульность: каждый компонент заменяем.

## Аудитория

- Молекулярные биологи — CRISPR, клонирование.
- Метаболические инженеры — пути, штаммы.
- Генетики — варианты, ассоциации.
- Биоинформатики — пайплайны, интеграции.
- PI — обзор, ревью, отчёты.
- Биотех-компании — R&D, документооборот.

## Отличие от конкурентов

| Конкуренты | Genome Studio |
|---|---|
| Benchling — ELN + молекулярка | + интент-слой, + симуляция |
| SnapGene — редактор | + планировщик, + BioKG |
| Geneious — анализ | + агент, + дерево последствий |
| Galaxy — пайплайны | + естественный язык |
| Jupyter — свобода | + доменные инструменты |
