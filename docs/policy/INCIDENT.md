# Инциденты

## Утечка dev-сборки
1. Немедленно отозвать ключ.
2. Пересобрать prod-сборку.
3. Уведомить команду.
4. Провести аудит логов.
5. Оценить ущерб.
6. Задокументировать.

## Утечка ключа
1. Отозвать ключ.
2. Пересобрать dev-сборку.
3. Сгенерировать новый ключ.
4. Проверить, не было ли несанкционированных сессий.

## Компрометация данных
1. Изолировать систему.
2. Уведомить пользователей.
3. Уведомить регулятора (если нужно).
4. Восстановить из бэкапа.
5. Провести post-mortem.
