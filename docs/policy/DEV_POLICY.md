# Политика dev-режима

## Назначение
Dev-режим используется ТОЛЬКО для тестирования продукта
разработчиком. Не для производства.

## Разрешено
- Симулировать летальные нокауты.
- Симулировать токсины (на моках).
- Тестировать DURC-скрининг (на моках).
- Отключать T0/T1/T2.
- Проверять edge cases.

## Запрещено
- Экспорт реальных патогенов.
- Заказ последовательностей.
- Интеграция с лабораторией.
- Отправка в облако.
- Шаринг dev-сборки.
- Использование в реальных экспериментах.

## Изоляция
- Только локально.
- Loopback only.
- Sandbox DB.
- Синтетические тест-данные.

## Аудит
Все dev-сессии логируются локально.
Логи не уходят в облако.
Хранятся до удаления разработчиком.

## Ответственность
Разработчик несёт ответственность за соблюдение политики.
Нарушение - основание для прекращения доступа.
