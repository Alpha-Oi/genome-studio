# Доступ к dev-режиму

## Кто имеет доступ
Только разработчик (founder/owner).

## Как получить
1. Собрать dev-сборку локально.
2. Сгенерировать подписанный ключ.
3. Активировать dev-режим.

## Как потерять
- Компрометация ключа.
- Нарушение политики.
- Уход из команды.

## Отзыв ключа
При уходе сотрудника:
1. Добавить ключ в revocation.list.
2. Пересобрать dev-сборку.
3. Удалить доступ к репозиторию.
