# Видение

## Долгосрочная цель

Стать стандартной средой для проектирования биологических
систем — от CRISPR-правок до метаболических путей и
синтетической биологии.

## Что это значит

Через 5 лет:
- Учёный открывает Genome Studio так же естественно,
  как программист открывает VS Code.
- Цель → план → симуляция → эксперимент → публикация
  в одной среде.
- Воспроизводимость по умолчанию.
- Коллаборация встроена.
- Институты используют платформу как стандарт.

## Философия продукта

### 1. Intent-first, не tool-first
Пользователь говорит «что», система думает «как».
Не «открой панель CRISPR», а «сделай нокаут гена X».

### 2. Explainable by default
Каждое предложение системы:
- имеет источник;
- имеет уверенность;
- имеет альтернативы.

### 3. Reproducible by default
Каждое действие фиксируется. Проект можно
воспроизвести через год.

### 4. Safety as architecture
Не «галочка в настройках», а три уровня:
T0 (наука), T1 (биобезопасность), T2 (закон).

### 5. Dev — отдельно
Разработчик может тестировать всё, но только локально
и изолированно. Prod-сборка не содержит dev-кода.

## Что НЕ делаем

- Не заменяем лабораторию. Симуляция — не эксперимент.
- Не даём медицинских советов.
- Не производим оружие.
- Не продаём данные пользователей.
- Не строим закрытую экосистему.
