# UI

## Принципы

1. Визуально прежде всего.
2. Воспроизводимость по умолчанию.
3. Отмена и версии.
4. Понятные ошибки.
5. Шаблоны.
6. Экспорт в стандарты.
7. Оффлайн-режим.
8. Горячие клавиши и палитра команд.

## Макет

Меню: Файл | Правка | Вид | Эксперимент | Анализ | Помощь

Левая панель: Проекты, Файлы, Образцы, Эксперименты

Центр (сверху вниз):
- Геномный браузер (IGV.js)
- Редактор / карта плазмиды
- Notebook / скрипт

Правая панель: Свойства, Guide настройки, Предсказание, Заметки

Статус-бар: Проект | Версия | Сохранено | seed

## Панели

- Projects - список проектов
- Chat - диалог с агентом
- Goal Tree - дерево цели (React Flow)
- Browser - IGV.js / JBrowse
- Editor - последовательности, плазмида (Monaco + SVG)
- Notebook - Jupyter (JupyterLab компоненты)
- Warnings - список warnings
- Dev Panel - только в dev

## Режимы

- Explore - исследование, ветвление
- Plan - построение плана
- Execute - симуляция
- Report - отчёт
