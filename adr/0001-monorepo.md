# ADR 0001: Монорепо

## Статус
Принято.

## Контекст
Продукт состоит из Python (backend), Rust (hot paths),
TypeScript (frontend), Rust -> WASM.

## Решение
Один монорепо с папками: backend/, core-rs/, ui/, wasm/.

## Обоснование
- Единый CI/CD.
- Общие типы (через генерацию).
- Проще рефакторить границы.
- Один PR - одна фича.

## Альтернативы
- Мультирепо - отвергнуто: сложнее синхронизация.
