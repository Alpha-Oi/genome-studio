# ADR 0002: Python-first

## Статус
Принято.

## Контекст
Нужно выбрать основной язык для MVP.

## Решение
Python для 80% кода. Rust только для hot paths.

## Обоснование
- Биоинформатика - Python (Biopython, pysam).
- ML - Python (PyTorch, HuggingFace).
- Быстрая разработка.
- Найм проще.

## Последствия
- Скорость на больших геномах - проблема.
- Решение: PyO3 + Rust для узких мест.
